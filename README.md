# Calculadora de Sistema Híbrido

Ferramenta web de **dimensionamento preliminar de consumo e componentes para sistemas híbridos de energia**, desenvolvida com HTML, JavaScript e Tailwind CSS.

## Funcionalidades identificadas

- Cadastro e estimativa de consumo de equipamentos.
- Apresentação dos resultados de consumo.
- Áreas para recomendação de inversor, baterias e geração.

## Executar

Abra `index.html` no navegador. É necessário acesso à internet para os recursos externos da interface.

## Aviso técnico

As estimativas não substituem projeto elétrico assinado por profissional habilitado. Antes de usar os resultados em uma instalação, confira normas, fatores de segurança e dados técnicos dos equipamentos.
